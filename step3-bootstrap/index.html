3단계: Bootstrap - 생산성 높이기

장고 개발자가 초기 프로토타입을 만들 때 가장 많이 사용하는 CSS 프레임워크입니다.

Bootstrap은 CDN으로 로드되어 즉시 사용 가능한 컴포넌트를 제공합니다.

1. CDN 연결

외부 라이브러리를 HTML에 로드하는 법

이 페이지도 Bootstrap을 CDN으로 로드하고 있습니다:

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
...
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>

장점: 파일을 다운로드하지 않아도 바로 사용 가능합니다.

5. 모달 (Modal)

모달은 사용자의 주의를 끌기 위해 오버레이 위에 표시되는 대화상자입니다.

6. 폼 (Forms)

Bootstrap의 폼 컴포넌트는 기본적으로 좋은 스타일링이 적용되어 있습니다.

7. 유틸리티 클래스

Bootstrap의 유틸리티 클래스를 사용하면 CSS를 추가로 작성할 필요가 거의 없습니다.
