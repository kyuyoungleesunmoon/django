## 6️⃣ MVC vs MTV

### MVC (Model-View-Controller)
```
┌──────────┐         ┌──────────┐         ┌──────────┐
│  Model   │ ←----→  │ Control  │ ←----→  │  View    │
│ (데이터) │         │ (로직)   │         │ (화면)   │
└──────────┘         └──────────┘         └──────────┘
```

### MTV (Model-Template-View) - Django
```
┌──────────┐         ┌──────────┐         ┌──────────┐
│  Model   │ ←----→  │   View   │ ←----→  │Template  │
│ (데이터) │         │ (로직)   │         │ (화면)   │
└──────────┘         └──────────┘         └──────────┘

이름만 다르고 역할은 같습니다!
- Model = MVC의 Model
- View = MVC의 Controller
- Template = MVC의 View
```

## 8️⃣ HTTP 메서드 vs Django

```
HTTP 메서드      Django          의미
─────────────────────────────────────────────
GET              request.method  조회 (웹페이지 로드)
POST             request.POST    제출 (폼 제출)
PUT              request.PUT     전체 수정
PATCH            request.PATCH   부분 수정
DELETE           request.DELETE  삭제

┌────────────────────────────────────────────────┐
│ Django 함수형 뷰에서 확인 예                    │
│                                                │
│ def post_update(request, pk):                 │
│     post = Post.objects.get(pk=pk)           │
│     if request.method == 'POST':             │ 
│         # 폼 제출됨 → 수정 처리               │
│         post.title = request.POST.get('title')
│         post.save()                          │
│         return redirect('post_detail')       │
│     else:                                    │
│         # GET → 폼 표시                      │
│         return render(request,               │
│             'blog/post_form.html')           │
└────────────────────────────────────────────────┘
```

## 9️⃣ 동적 URL과 고정 URL

```
┌──────────────────────────────────────────────────────────┐
│ 고정 URL (모든 사용자에게 동일)                            │
├──────────────────────────────────────────────────────────┤
│ /posts/          ← 포스트 목록                           │
│ /post/create/    ← 포스트 작성                           │
│ /register/       ← 회원가입                             │
│ /login/          ← 로그인                               │
│ /logout/         ← 로그아웃                             │
└──────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────┐
│ 동적 URL (변수 포함)                                      │
├──────────────────────────────────────────────────────────┤
│ /post/1/         ← 포스트 ID=1의 상세 페이지            │
│ /post/2/         ← 포스트 ID=2의 상세 페이지            │
│ /post/3/         ← 포스트 ID=3의 상세 페이지            │
│ /post/1/edit/    ← 포스트 ID=1의 수정 페이지            │
│ /post/1/delete/  ← 포스트 ID=1의 삭제 페이지            │
└──────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────┐
│ urls.py에서 동적 URL 정의                                │
├──────────────────────────────────────────────────────────┤
│ path('post/<int:pk>/', views.post_detail)               │
│                                                          │
│ <int:pk>  ← int는 자료형, pk는 변수명                   │
│            URL에서 숫자만 허용                            │
│            views에서 pk로 접근                           │
│                                                          │
│ /post/1/        ← pk=1                                   │
│ /post/123/      ← pk=123                                │
│ /post/hello/    ← 매칭 안 됨 (숫자 아님)                 │
└──────────────────────────────────────────────────────────┘
```
