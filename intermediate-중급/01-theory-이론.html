🎓 중급 과정 - Flexbox, Grid, 반응형 디자인 이론

학습 목표: 현대적인 레이아웃 기법과 반응형 웹 디자인을 마스터합니다.

📌 Part 1: Flexbox (유연한 박스 레이아웃)

1.1 Flexbox란?

Flexbox는 1차원 레이아웃 시스템으로, 가로(row) 또는 세로(column) 방향으로 아이템을 배치합니다.

  • ✅ 정렬, 배분, 순서 변경이 매우 쉬움
  • ✅ 반응형 디자인에 최적화
  • ✅ 실무에서 가장 많이 사용

1.2 Flexbox 기본 구조

.container { display: flex; /* Flex 컨테이너 생성 */ } .item { /* Flex 아이템 */ }

용어:

  • Flex Container: display: flex가 적용된 부모 요소
  • Flex Item: Flex Container의 직접적인 자식 요소
  • Main Axis: 주축 (기본: 가로)
  • Cross Axis: 교차축 (기본: 세로)

1.3 Flex Container 속성

① flex-direction (방향)

flex-direction: row; /* 가로 (기본값) */ flex-direction: row-reverse; /* 가로 역방향 */ flex-direction: column; /* 세로 */ flex-direction: column-reverse; /* 세로 역방향 */

② justify-content (주축 정렬)

값 설명 용도

flex-end 끝점 정렬 오른쪽 정렬
center 중앙 정렬 가운데 정렬
space-between 양쪽 끝 배치 후 균등 분배 아이템 사이 간격
space-around 아이템 주변에 균등 간격 전체 균등 배치
space-evenly 모든 간격 동일 완전 균등 배치

③ align-items (교차축 정렬)

값 설명
stretch 늘려서 채우기 (기본값)
flex-start 위쪽 정렬
flex-end 아래쪽 정렬
center 수직 중앙 정렬
baseline 텍스트 베이스라인 정렬

④ flex-wrap (줄 바꿈)

flex-wrap: nowrap; /* 한 줄에 모두 배치 (기본값) */ flex-wrap: wrap; /* 넘치면 다음 줄로 */ flex-wrap: wrap-reverse; /* 역방향 줄 바꿈 */

⑤ gap (간격)

gap: 20px; /* 모든 방향 20px */ gap: 10px 20px; /* 세로 10px, 가로 20px */ row-gap: 15px; /* 세로 간격만 */ column-gap: 25px; /* 가로 간격만 */

1.4 Flex Item 속성

① flex-grow (확대)

남은 공간을 얼마나 차지할지 비율로 지정

.item1 { flex-grow: 1; } /* 1배 */ .item2 { flex-grow: 2; } /* 2배 (2배 더 크게) */

② flex-shrink (축소)

공간이 부족할 때 얼마나 줄어들지 지정

flex-shrink: 1; /* 축소 가능 (기본값) */ flex-shrink: 0; /* 축소 불가 */

③ flex-basis (기본 크기)

flex-basis: 200px; /* 기본 너비 200px */ flex-basis: auto; /* 내용 크기 (기본값) */

④ flex (축약형) - 실무 필수!

flex: 1; /* flex-grow: 1, flex-shrink: 1, flex-basis: 0 */ flex: 0 0 auto; /* 고정 크기 */ flex: 1 1 300px; /* grow, shrink, basis 모두 지정 */
💡 실무 팁:
flex: 1은 "남은 공간을 동등하게 나눠 가져라"는 의미로 매우 자주 사용됩니다!

📌 Part 2: Grid (격자 레이아웃)

2.1 Grid란?

Grid는 2차원 레이아웃 시스템으로, 가로와 세로를 동시에 제어합니다.

  • ✅ 복잡한 레이아웃 구현 가능
  • ✅ 행(row)과 열(column) 동시 제어
  • ✅ 웹 페이지 전체 레이아웃에 적합

2.2 Grid 기본 구조

.container { display: grid; grid-template-columns: 1fr 1fr 1fr; /* 3개 컬럼, 동일 크기 */ grid-template-rows: 100px 200px; /* 2개 행 */ gap: 20px; }

2.3 Grid Container 속성

① grid-template-columns (컬럼 정의)

/* 픽셀 단위 */ grid-template-columns: 200px 300px 400px; /* 비율 단위 (fr) */ grid-template-columns: 1fr 2fr 1fr; /* 1:2:1 비율 */ /* 자동 크기 */ grid-template-columns: auto 1fr auto; /* repeat 함수 */ grid-template-columns: repeat(3, 1fr); /* 3개 컬럼, 동일 크기 */ /* 혼합 */ grid-template-columns: 200px 1fr 2fr;

② grid-template-rows (행 정의)

grid-template-rows: 100px 200px; grid-template-rows: repeat(3, 150px); grid-template-rows: auto 1fr auto; /* 헤더-콘텐츠-푸터 */

③ gap (간격)

gap: 20px; /* 모든 간격 20px */ gap: 10px 20px; /* 행 간격 10px, 열 간격 20px */ row-gap: 15px; column-gap: 25px;

2.4 Grid Item 배치

① grid-column (컬럼 위치)

.item { grid-column: 1 / 3; /* 1번 라인부터 3번 라인까지 */ grid-column: span 2; /* 2개 컬럼 차지 */ }

② grid-row (행 위치)

.item { grid-row: 1 / 4; /* 1번 라인부터 4번 라인까지 */ grid-row: span 3; /* 3개 행 차지 */ }

③ grid-area (영역 이름으로 배치)

.container { display: grid; grid-template-areas: "header header header" "sidebar main main" "footer footer footer"; } .header { grid-area: header; } .sidebar { grid-area: sidebar; } .main { grid-area: main; } .footer { grid-area: footer; }
💡 실무 팁: grid-template-areas는 가독성이 좋아서 페이지 전체 레이아웃에 자주 사용됩니다!

📌 Part 3: 반응형 디자인 (Responsive Design)

3.1 반응형 디자인이란?

하나의 웹사이트가 모든 기기(데스크톱, 태블릿, 모바일)에서 최적화되어 보이도록 하는 기법입니다.

  • ✅ 미디어 쿼리 사용
  • ✅ 유연한 레이아웃 (Flexbox, Grid)
  • ✅ 유연한 이미지 (max-width: 100%)
  • ✅ viewport 설정

3.2 viewport 설정 (필수!)

<meta name="viewport" content="width=device-width, initial-scale=1.0">

모바일 기기에서 올바른 크기로 표시되도록 합니다.

3.3 미디어 쿼리 (Media Queries)

화면 크기에 따라 다른 CSS를 적용합니다.

기본 문법

/* 768px 이하 (태블릿, 모바일) */ @media (max-width: 768px) { .container { flex-direction: column; } } /* 992px 이상 (데스크톱) */ @media (min-width: 992px) { .container { max-width: 1200px; } } /* 범위 지정 */ @media (min-width: 768px) and (max-width: 1024px) { /* 태블릿 전용 스타일 */ }

실무 브레이크포인트

기기 화면 크기 미디어 쿼리
모바일 (세로) ~ 576px @media (max-width: 576px)
모바일 (가로) / 태블릿 (세로) 576px ~ 768px @media (min-width: 576px)
태블릿 (가로) 768px ~ 992px @media (min-width: 768px)
데스크톱 992px ~ 1200px @media (min-width: 992px)
대형 데스크톱 1200px ~ @media (min-width: 1200px)

3.4 반응형 레이아웃 패턴

① 컬럼 드롭 (Column Drop)

/* 데스크톱: 3컬럼 */ .container { display: flex; gap: 20px; } .item { flex: 1; } /* 태블릿: 2컬럼 */ @media (max-width: 768px) { .container { flex-wrap: wrap; } .item { flex: 0 0 calc(50% - 10px); } } /* 모바일: 1컬럼 */ @media (max-width: 576px) { .item { flex: 0 0 100%; } }

② Grid 반응형

.container { display: grid; grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); gap: 20px; } /* auto-fit: 자동으로 컬럼 수 조정 */ /* minmax(250px, 1fr): 최소 250px, 최대 1fr */
💡 실무 팁: auto-fit과 minmax를 조합하면 미디어 쿼리 없이도 반응형을 구현할 수 있습니다!

3.5 반응형 이미지

img { max-width: 100%; /* 부모 요소보다 크지 않게 */ height: auto; /* 비율 유지 */ } /* 고해상도 대응 */ @media (-webkit-min-device-pixel-ratio: 2), (min-resolution: 192dpi) { .logo { background-image: url('logo@2x.png'); } }

⚠️ 주의사항

  • 모바일 우선(Mobile-First) 접근 권장
  • 미디어 쿼리 순서 중요 (작은 화면 → 큰 화면)
  • 테스트는 실제 기기에서 확인
  • 성능 고려 (이미지 최적화, 불필요한 리소스 제거)
