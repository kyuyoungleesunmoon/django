4단계: Django Template Language (DTL) 맛보기

HTML과 CSS 배운 것을 장고에 녹여내는 단계입니다.

1️⃣ 템플릿 상속 (Template Inheritance)

중복 코드를 제거하고 일관성 있는 레이아웃을 유지하는 핵심 개념입니다.

base.html (부모 템플릿)

모든 페이지에서 공통으로 사용하는 HTML 구조를 정의합니다:

<!DOCTYPE html>
<html>
<head>
    <title>{% block title %}기본 제목{% endblock %}</title>
</head>
<body>
    <nav>네비게이션</nav>
    
    {% block content %}
    기본 콘텐츠
    {% endblock %}
    
    <footer>푸터</footer>
</body>
</html>
page.html (자식 템플릿)

부모 템플릿을 상속받고 {% block %} 부분만 오버라이드합니다:

{% extends 'base.html' %}

{% block title %}
    내 페이지
{% endblock %}

{% block content %}
    <h1>페이지 제목</h1>
    <p>여기에 페이지별 콘텐츠를 작성합니다.</p>
{% endblock %}
💡 장점:
  • 네비게이션, 푸터 등 반복되는 부분을 한 번만 작성
  • 레이아웃 변경 시 base.html만 수정하면 모든 페이지에 적용
  • 코드 유지보수가 훨씬 쉬워집니다

2️⃣ 데이터 출력 ({{ variable }})

백엔드에서 보낸 변수를 화면에 표시합니다.

views.py (Django 백엔드)
from django.shortcuts import render

def home(request):
    context = {
        'name': '홍길동',
        'age': 25,
        'posts_count': 5,
        'is_logged_in': True,
        'items': ['Python', 'Django', 'JavaScript'],
    }
    return render(request, 'home.html', context)
home.html (Django 템플릿)
<h1>안녕하세요, {{ name }}님!</h1>
<p>나이: {{ age }}</p>
<p>작성한 게시물: {{ posts_count }}개</p>
렌더링 결과

안녕하세요, 홍길동님!

나이: 25

작성한 게시물: 5개

💡 사용법:
  • {{ variable }} - 변수 값을 출력
  • {{ variable|default:"기본값" }} - 변수가 없으면 기본값 출력
  • {{ variable|safe }} - HTML 태그를 안전하게 출력

3️⃣ 제어문 ({% if %}, {% for %})

조건문과 반복문을 사용하여 동적인 HTML을 생성합니다.

{% if %} - 조건문

조건에 따라 다른 HTML을 출력합니다:

{% if is_logged_in %}
    <p>{{ name }}님이 로그인 중입니다.</p>
    <button>로그아웃</button>
{% else %}
    <button>로그인</button>
{% endif %}
더 복잡한 조건:
{% if age >= 18 %}
    <p>성인입니다.</p>
{% elif age >= 13 %}
    <p>청소년입니다.</p>
{% else %}
    <p>어린이입니다.</p>
{% endif %}

✅ 홍길동님이 로그인 중입니다.

{% for %} - 반복문

리스트나 쿼리셋을 반복하여 각 항목의 HTML을 생성합니다:

<ul>
{% for item in items %}
    <li>{{ item }}</li>
{% endfor %}
</ul>
렌더링 결과:
  • Python
  • Django
  • JavaScript
반복 인덱스 사용:
{% for item in items %}
    <p>{{ forloop.counter }}. {{ item }}</p>
{% endfor %}

forloop.counter    - 1부터 시작하는 반복 번호
forloop.counter0   - 0부터 시작하는 반복 번호
forloop.first      - 첫 번째 항목인지 여부
forloop.last       - 마지막 항목인지 여부
렌더링 결과:

1. Python

2. Django

3. JavaScript

{% for %} + {% if %} 조합 (실무 예제)

게시물 목록을 표시하는 실제 예제:

<table class="table">
<thead>
    <tr>
        <th>번호</th>
        <th>제목</th>
        <th>작성자</th>
        <th>상태</th>
    </tr>
</thead>
<tbody>
{% for post in posts %}
    <tr>
        <td>{{ forloop.counter }}</td>
        <td>{{ post.title }}</td>
        <td>{{ post.author }}</td>
        <td>
            {% if post.is_published %}
                <span class="badge bg-success">발행됨</span>
            {% else %}
                <span class="badge bg-warning">초안</span>
            {% endif %}
        </td>
    </tr>
{% endfor %}
</tbody>
</table>

{% empty %} - 빈 리스트 처리

리스트가 비어있을 때 표시할 내용:

{% for item in items %}
    <p>{{ item }}</p>
{% empty %}
    <p class="text-muted">아이템이 없습니다.</p>
{% endfor %}

📚 실전 예제: 블로그 목록 페이지

views.py
def blog_list(request):
    posts = [
        {'id': 1, 'title': 'Django 시작하기', 'author': '홍길동', 'is_published': True},
        {'id': 2, 'title': 'CSS 완벽 가이드', 'author': '김철수', 'is_published': True},
        {'id': 3, 'title': 'JavaScript 고급', 'author': '이영희', 'is_published': False},
    ]
    
    context = {
        'posts': posts,
        'total_posts': len(posts),
    }
    return render(request, 'blog_list.html', context)
blog_list.html ({% extends %} 포함)
{% extends 'base.html' %}

{% block title %}블로그 - 모든 게시물{% endblock %}

{% block content %}
<h1>블로그 📝</h1>
<p>총 {{ total_posts }}개의 게시물이 있습니다.</p>

{% if posts %}
    <div class="row">
    {% for post in posts %}
        <div class="col-md-4 mb-4">
            <div class="card">
                <div class="card-body">
                    <h5 class="card-title">{{ post.title }}</h5>
                    <p class="card-text">
                        작성자: {{ post.author }}
                    </p>
                    {% if post.is_published %}
                        <span class="badge bg-success">발행됨</span>
                    {% else %}
                        <span class="badge bg-warning">초안</span>
                    {% endif %}
                </div>
            </div>
        </div>
    {% endfor %}
    </div>
{% else %}
    <div class="alert alert-info">
        아직 게시물이 없습니다.
    </div>
{% endif %}
{% endblock %}

📌 4단계 정리

{% extends %} - 템플릿 상속
  • ✅ 코드 중복 제거
  • ✅ 레이아웃 일관성
  • ✅ 유지보수 효율
{{ variable }} - 데이터 출력
  • ✅ 백엔드 데이터 표시
  • ✅ 동적 콘텐츠
  • ✅ 필터 사용 가능
{% if %} - 조건문
  • ✅ 조건부 표시
  • ✅ 권한 확인
  • ✅ 상태에 따른 UI
{% for %} - 반복문
  • ✅ 리스트 반복
  • ✅ 테이블/카드 생성
  • ✅ forloop 변수 활용
