🎓 고급 과정 - Bootstrap & Django Template Language

실무에서 즉시 사용 가능한 프레임워크와 템플릿 엔진을 마스터합니다.

📌 Part 1: Bootstrap 5

1.1 Bootstrap이란?

세계에서 가장 인기 있는 CSS 프레임워크입니다.

  • 빠른 프로토타입 제작
  • 반응형 디자인 기본 제공
  • 다양한 컴포넌트
1.2 CDN 연결
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet"> <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>
1.3 Grid System (12컬럼)
<div class="row"> <div class="col-md-4">1/3</div> <div class="col-md-8">2/3</div> </div>

📌 Part 2: Django Template Language

2.1 템플릿 상속
{% extends 'base.html' %} {% block content %} <h1>페이지 제목</h1> {% endblock %}
2.2 변수 출력
{{ variable }} {{ user.username }} {{ post.title|title }}
2.3 제어문
{% if user.is_authenticated %} 환영합니다! {% else %} 로그인하세요. {% endif %} {% for item in items %} {{ item }} {% endfor %}
