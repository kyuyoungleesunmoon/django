📌 Part 1: HTML 기초

1.1 HTML이란?

HTML (HyperText Markup Language)은 웹 페이지의 구조를 만드는 언어입니다.

  • HyperText: 링크를 통해 다른 페이지로 이동 가능
  • Markup: 태그로 내용을 표시
  • Language: 브라우저가 이해하는 언어

1.2 HTML 기본 문서 구조

<!DOCTYPE html> ← 문서 타입 선언 (HTML5) <html lang="ko"> ← HTML 문서 시작 <head> ← 메타 정보 영역 <meta charset="UTF-8"> ← 문자 인코딩 <title>페이지 제목</title> </head> <body> ← 실제 콘텐츠 영역 <h1>환영합니다</h1> <p>내용이 들어갑니다.</p> </body> </html>

1.3 주요 HTML 태그

태그 용도 예제
<h1> ~ <h6> 제목 (Heading) <h1>대제목</h1>
<p> 문단 (Paragraph) <p>문단입니다.</p>
<a> 링크 (Anchor) <a href="url">클릭</a>
<img> 이미지 <img src="image.jpg" alt="설명">
<div> 컨테이너 (블록) <div>그룹</div>
<span> 인라인 컨테이너 <span>강조</span>
<ul>, <ol>, <li> 리스트 <ul><li>항목</li></ul>

1.4 시맨틱 태그 (Semantic Tags)

의미가 있는 태그를 사용하면 SEO(검색 최적화)에 유리하고 코드 가독성이 좋아집니다.

태그 의미 사용 위치
<header> 헤더 (상단 영역) 로고, 네비게이션
<nav> 네비게이션 메뉴, 링크
<main> 주요 콘텐츠 페이지의 핵심 내용
<section> 섹션 (구역) 주제별 콘텐츠
<article> 독립적인 콘텐츠 블로그 포스트, 뉴스
<aside> 부가 정보 사이드바
<footer> 푸터 (하단 영역) 저작권, 연락처
<body> <header>헤더 영역</header> <nav>메뉴 영역</nav> <main> <section>섹션 1</section> <section>섹션 2</section> </main> <footer>푸터 영역</footer> </body>

1.5 폼 (Form) 요소 - Django 연동의 핵심!

폼은 사용자 입력을 받아 서버로 전송하는 중요한 요소입니다.

<form method="POST" action="/submit"> <!-- 텍스트 입력 --> <input type="text" name="username" placeholder="이름"> <!-- 이메일 입력 --> <input type="email" name="email" placeholder="이메일"> <!-- 비밀번호 입력 --> <input type="password" name="password"> <!-- 라디오 버튼 (단일 선택) --> <input type="radio" name="gender" value="male"> 남성 <input type="radio" name="gender" value="female"> 여성 <!-- 체크박스 (다중 선택) --> <input type="checkbox" name="interests" value="coding"> 코딩 <!-- 드롭다운 --> <select name="country"> <option value="korea">대한민국</option> <option value="usa">미국</option> </select> <!-- 제출 버튼 --> <button type="submit">제출</button> </form>
💡 핵심: name 속성이 Django에서 데이터를 받는 키(key)가 됩니다!
예: request.POST['username'], request.POST['email']

📌 Part 2: CSS 기초

2.1 CSS란?

CSS (Cascading Style Sheets)는 HTML 요소의 스타일(디자인)을 지정하는 언어입니다.

  • Cascading: 스타일이 위에서 아래로 적용
  • Style: 색상, 크기, 배치 등
  • Sheets: 스타일 규칙의 모음

2.2 CSS 작성 방법 3가지

① 인라인 스타일 (권장하지 않음)

<p style="color: red; font-size: 20px;">빨간 글씨</p>

② 내부 스타일시트 (소규모 프로젝트)

<head> <style> p { color: red; font-size: 20px; } </style> </head>

③ 외부 스타일시트 (추천!)

<!-- HTML 파일 --> <head> <link rel="stylesheet" href="styles.css"> </head> /* styles.css 파일 */ p { color: red; font-size: 20px; }

2.3 CSS 선택자 (Selectors)

선택자 표기법 예제 설명
태그 선택자 태그명 p { } 모든 <p> 태그 선택
클래스 선택자 .클래스명 .box { } class="box"인 요소
아이디 선택자 #아이디명 #header { } id="header"인 요소
전체 선택자 * * { } 모든 요소 선택
/* 태그 선택자 */ p { color: blue; } /* 클래스 선택자 */ .highlight { background-color: yellow; } /* 아이디 선택자 */ #main-title { font-size: 32px; }

2.4 CSS 박스 모델 (Box Model)

모든 HTML 요소는 박스로 이루어져 있습니다.

Content (내용)

■ Content → ■ Padding → ■ Border → ■ Margin

.box { width: 200px; /* 너비 */ height: 100px; /* 높이 */ padding: 20px; /* 안쪽 여백 */ border: 5px solid #000; /* 테두리 */ margin: 10px; /* 바깥쪽 여백 */ }
💡 box-sizing 팁:
box-sizing: border-box;를 사용하면 padding과 border가 width에 포함됩니다!
→ 계산이 쉬워져서 실무에서 거의 필수로 사용합니다.

2.5 주요 CSS 속성

색상 관련

color: red; /* 글자 색 */ background-color: #f0f0f0; /* 배경색 */

텍스트 관련

font-size: 16px; /* 글자 크기 */ font-weight: bold; /* 굵기 */ text-align: center; /* 정렬 */ line-height: 1.6; /* 줄 간격 */

여백 관련

margin: 10px; /* 바깥 여백 (4방향) */ margin-top: 20px; /* 위쪽만 */ padding: 15px 20px; /* 안쪽 여백 (위아래 좌우) */

테두리 관련

border: 1px solid #000; /* 테두리 */ border-radius: 5px; /* 둥근 모서리 */

2.6 display 속성 (중요!)

값 특징 예시
block 한 줄 전체 차지 <div>, <p>, <h1>
inline 내용만큼만 차지 <span>, <a>
inline-block inline처럼 배치되지만 크기 설정 가능 버튼, 작은 박스
none 화면에 표시 안 함 숨김 처리
